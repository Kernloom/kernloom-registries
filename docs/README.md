# Kernloom Registry Docs

Use these docs by intent:

| Need | Read |
|---|---|
| Understand which registry defines which policy/target concept | `registry-reference-for-policy-intents.md` |
| Author or extend registry entries | `registry-authoring-guide.md` |
| Understand runtime compatibility and rejection rules | `compatibility-policy.md` |
| Follow the registry integration work plan | `integration-plan.md` |
| Write Natural Intent vocabulary quickly | `../../kernloom-forge/docs/natural-intent-vocabulary-cheat-sheet.md` |

Registry docs define the canonical standard. Forge docs show how humans author
and test policies against that standard.
